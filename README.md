# 球赛智析

本项目是足球比赛预测本地 Web App 的 MVP 原型。

## 竞彩选场与国际市场分析

1. 从赛事列表选择比赛，或上传竞彩截图后核对日期、球队和主客顺序。
2. 点击“确认加入竞彩候选池”。竞彩让球可留空，填写时只接受整数，负数表示主队让球。
3. 在候选池自动获取，或手动录入合法获得的国际胜平负十进制赔率、公司名称与实际报价时间。
4. 系统以赔率倒数归一化计算市场隐含概率，保存每次报价，比较同一来源的概率变化。

排序依据为最高市场隐含概率，不是历史准确率或投注收益。超过六小时的报价、已开赛赛事和演示赛事不列入推荐。旧 events.handicap 字段不会自动当作竞彩让球。仅凭三项胜平负赔率不能生成可靠的总进球、比分或半全场分布。本版国际分析不使用演示球队参数。

候选池中的非演示赛事可点击“自动获取赔率”，由 API-Football 按比赛逐场获取赛前胜平负赔率并保存博彩公司、时间和隐含概率；API-Football 无报价或未配置 key 时仍可手动录入。系统只调用官方 API，不做全网搜索或绕过访问限制；具体赛事是否覆盖以供应商返回的 coverage 为准。

候选池中的五大联赛、欧冠和指定国际赛事可点击“更新首发/伤停”，或在生成预测时自动更新 API-Football 赛季主客场攻防参数、伤停和首发；攻防统计按联赛/赛季/球队在本地缓存，赛前上下文默认缓存 1 小时。低级联赛不触发这组请求。

验证：`python3 -B -m unittest -v`。

## 启动

```bash
python3 app.py
```

然后打开 http://127.0.0.1:8765 。首次启动会创建 `football_predict.db`，并写入少量演示赛事和球队统计数据。

## 当前能力

- 本地 SQLite 赛事存储
- 赛事列表和联赛筛选
- 基于同一比分矩阵的胜平负、体彩让球、总进球、半全场和比分概率
- 总进球 0–6 球与 7+ 球分布、比分 Top 5、概率差距和数据完整度
- 模型版本 `poisson-mvp-0.2`；旧数据库会在启动时迁移活动版本，不覆盖历史预测
- 保存每次预测结果
- 预测历史查询
- 赛后比分录入 API
- 自动记录特征快照、模型指标和模型版本
- 基于历史赛果的安全概率校准（样本不足时不会自动切换）
- 赛事批量导入 API
- 本地图片 OCR 适配器与赛事候选匹配（依赖可用的 macOS Swift/Vision 工具链）
- 竞彩候选池入口：支持选择胜平负、让球、总进球、半全场和比分，并一键批量生成预测
- 串关分析：从候选池选择至少两场胜平负，计算组合命中概率和组合赔率
- 赛事列表和候选池日期筛选；已配置的常见球队、赛事名称优先显示中文，原始英文名保留在数据层
- 预留公开数据采集适配器
- API-Football 赛前上下文：赛季攻防、实时伤停、首发阵容和数据完整度提示

## 同步公开赛事

项目通过两个公开 API 批量同步未来 14 天赛事：

- football-data.org：英超、西甲、德甲、意甲、法甲、欧冠、世界杯和欧洲杯。
- API-Football：亚洲杯、亚运会、美洲杯、非洲杯、奥运男足、世俱杯、日职、日乙和解放者杯。

先从对应服务获取免费 API key。推荐首次配置时复制 `.env.example` 为项目根目录的 `.env`，填入真实 key；程序启动时会自动读取，之后不需要每次执行 `export`：

```bash
cp .env.example .env
# 编辑 .env，填写两个 key
python3 app.py
```

也可以继续使用终端环境变量；环境变量优先于 `.env` 中的同名配置。

在页面点击“同步公开赛事”即可。两个 key 是不同供应商的凭据，不能互换；它们只在本地后端进程环境中使用，不会发送到浏览器或写入数据库。未配置 API-Football 时，系统仍会同步 football-data.org，并明确提示已跳过对应国际赛事和赛前上下文。

同步按赛事和日期区间批量调用，不按比赛逐场调用。常规 14 天窗口通常需要 football-data.org 8 次请求；API-Football 先用 1 次请求读取当年杯赛目录，再仅对日期范围内实际举办的目标赛事各调用 1 次。赛前上下文首次获取每场最多约 5 次请求（赛事匹配、两队赛季攻防、伤停、首发），相同球队/赛季的攻防参数会复用本地缓存，1 小时内再次预测不重复请求上下文。API-Football 免费档为 100 次/天时，日常同步和十几场以内的后续分析通常可以接受，但具体可用数据仍以各赛事 `coverage` 为准。

## 本地 OCR

截图识别使用 macOS 的 Vision 框架。若上传图片提示 Swift/Vision 工具链不可用，请先更新或重新安装 Xcode Command Line Tools，然后重启应用；图片会保留在本地 `uploads/` 目录中。

当前数据是演示数据，不应视为实时数据或实际预测建议。
